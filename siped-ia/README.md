# SIPED-IA: Sistema de Inteligencia Pedagógica
## Colegio La Salle La Paz - Nivel Primario

Este proyecto es un prototipo funcional (MVP) de un sistema basado en Inteligencia Artificial (Arquitectura Transformer/LLM) diseñado para apoyar la toma de decisiones pedagógicas basada en datos cualitativos y cuantitativos.

### 🎯 Objetivo del Proyecto
Optimizar el análisis del desempeño estudiantil para generar rutas de intervención personalizada, permitiendo a los docentes anticipar dificultades de aprendizaje y fortalecer la práctica pedagógica bajo el modelo **TPACK**.

### 🛠️ Tecnologías Utilizadas
- **Frontend:** Vanilla HTML5, CSS3 y JavaScript puro (sin dependencias ni compiladores).
- **Estilos:** Tailwind CSS (vía CDN).
- **Iconografía:** Lucide Icons (vía CDN).
- **IA:** Google Gemini API (Fetch nativo de JavaScript).

### 🏛️ Marco Ético
El sistema está alineado con las recomendaciones de la **UNESCO (2021)** sobre la ética de la IA en educación:
- **Supervisión Humana:** El docente siempre tiene la decisión final.
- **Transparencia:** Procesos de análisis claros y explicables.
- **No Estigmatización:** Las recomendaciones son de apoyo, no de etiquetado negativo.

### 🚀 Funcionalidades del MVP Interactivo
1. **Dashboard de Patrones:** Visualización rápida de rendimiento y participación por estudiante.
2. **Análisis Cualitativo:** Entrada de texto para registrar observaciones diarias.
3. **Generación de Recomendaciones (Simulación):** Simulación de IA para obtener rutas de intervención pedagógica, apoyo socioemocional e integración TPACK.

### 📂 Estructura del Portafolio de Evidencias
El proyecto incluye un menú lateral que conecta con:
- `pages/siped_ia_P1.html`: Diseño teórico y simulación estática del sistema.
- `pages/siped_ia_P2.html`: Bitácora de Innovación, análisis FODA y Matriz Tecnológica.
- `pages/recursos.html`: Galería de imágenes, visor de PDFs del proyecto y video de presentación integrados directamente en el navegador.

### 📋 Requisitos para Ejecución Local
1. Clonar el repositorio.
2. Abrir el archivo `index.html` en cualquier navegador web moderno (Chrome, Firefox, Edge).
3. **¡Listo!** La aplicación se ejecutará en modo simulación (sin requerir de una API Key real). No se necesita Node.js ni configurar archivos extra.
